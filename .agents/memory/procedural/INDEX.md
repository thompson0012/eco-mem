# Procedural memory

定位：穩定的行動方式。回答「這件事該怎麼做」。
何時用：要執行已驗證流程，而不是臨時猜下一步。
用途：把規則變成可重複、可驗證的做法。
存哪些：指向已有 skill / workflow / 測試 / checklist 的指針；尚未出師的短清單（另檔）。
不存：把 skill 正文複製進來；把一次成功誤當成流程；語義規則本身（那是 semantic）。
何時更新：被反覆驗證 → 出師成 skill，這裡改成指針。失效 → `deprecated`。

CRUD 協議只活在 [`../../skills/eco-mem/SKILL.md`](../../skills/eco-mem/SKILL.md)。本屜特例：優先指針，不複製正文。
